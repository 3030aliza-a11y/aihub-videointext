🎬 Tách Video Thành Văn Bản

Tải video/audio lên hoặc dán link file trực tiếp → chuyển giọng nói thành văn bản đầy đủ (không có mốc thời gian).

1 API Key OpenAI

Chưa có key? Tạo tại platform.openai.com/api-keys. Chi phí khoảng $0.006/phút audio (~150đ/phút), trừ thẳng vào tài khoản OpenAI của bạn.

2 Nguồn video

📁 Tải file lên
🔗 Dán link file
⚠️ Chỉ nhận link file trực tiếp. Link trang xem video như youtube.com/watch, tiktok.com/@..., facebook.com/... không dùng được vì đó là trang web chứ không phải file — hãy tải video đó về máy rồi dùng tab "Tải file lên" ở trên.
